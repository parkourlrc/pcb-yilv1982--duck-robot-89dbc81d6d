# IMU 板②（jyg9 GD32 社区版）台架验收单

> 2026-10-14 建。对象：**单 3P 口**的 IMU 板，照片判别为 jyg9 / microduck-community-kit 成品版（GD32F303 LQFP48 + 降压前端），判别证据与照片存档见 [IMU 版本调研](./references/imu-to-dxl-variants-20261009/research.md) 补充节及 [照片索引](./photos/README.md)。
> **2026-10-16 精简（用户指示：非必要测试不做，先跑通有问题再说）**：本板免刷、宽压直挂，现行最短路径 = 接线前目视核对针序（接反会烧板，保留）→ 挂 7.4V 限流总线 → ping 200 应答即可；下文分步台架流程与 13 项深度验收降级为**异常排查参考**，出问题再跑。详见 [HAT 测试单·最短路径](./hat-v1.2-test.md)。
> 与板①（ScrapMeta v0.3）的区别：**本板免刷固件**（出厂 DXL 2.0 + 飞特双协议自动识别，ID 200）；**供电按 0.2 官方图纸需 ≥6.5V 冷启动（EN 分压设定，维持下限 ≈5.93V），5V 必不启动**——这点与板①刷机阶段"只给 5V"的红线恰好相反，两块板不要套同一份供电习惯。Buck=ETA2845S2G（5~38V、OVP 37.5V），电源树与启动电压计算见 [jyg9 电源分析](./references/imu-jyg9-power-5v-20261026/research.md)（2026-10-26）。
> **2026-10-26 撤回 5V 过渡方案**：此前"手边只有 5V 可短暂试机看点亮"的说法不再有效——按官方原理图 EN 分压（R3 100K/R4 30K → 0.231×VBATT，阈值 1.5V），**5V 输入时芯片保持关断，板上不可能点亮，5V 试机无意义**；欠压不伤板的判断不变。验收一律 7.4V。
> 本单只做**台架通信验收**，不做整机带载；结果不代表装入整机后的表现。

## 步骤

| 顺序 | 做什么 | 通过判据 |
|---|---|---|
| 0 断电核线 | 全部断开。按 [三板舵机座对比](./photos/board-servo-socket-pinout.png) 核对板座针序（EH 座 1=GND 2=V+ 3=DATA，照片推断 + 官方 0.2 图纸双重一致；板上如焊有并联 PH 2mm 座注意其针序相反 1=DATA 2=V+ 3=GND，**勿混插**）：蜂鸣档确认 GND 脚对板内地网连通、V+ 与 GND 之间无短路；电源输出关闭状态下预设 7.4V / 0.2A，复核正负 | 针序明确、无短路；电源空载输出 7.4V 左右。针序无法确认则停止，不上电试错。⚠️ 板上电源正极无保险，反接只靠 TVS 正向导通兜底必烧——核线不可省 |
| 1 空板供电 | 只接 V+/GND 两线（DATA 悬空），开输出 | 电流稳定在几十 mA 量级、无持续顶限、无异常温升；板上有指示灯则记录状态。顶限或发热立即关输出排查 |
| 2 接总线 | **关输出**，接 DATA/GND 到 URT-2（V+ 仍走可调电源，共地）；URT-2 插电脑 USB，`2-查COM口.bat` 记 COM 号 | 接线完成后再开输出；无异常电流变化 |
| 3 imu200 验收 | 双击 `3-验收-imu200.bat`，输入 COM 号，跑 13 项检查 | **全 PASS = 主控 robotd 飞特补丁会认这块板**。日志自动存 `tools/imu200/logs/`；有 FAIL 保留日志发回来逐条判 |
| 4 晃动验证 | 验收通过后在工具读数期间轻晃/翻转板子 | 四元数/陀螺读数随姿态连续变化、不冻结、无丢帧突增——确认真 IMU 数据而非静态缓存 |

## 停止条件与边界

- **停止条件**：针序不明、上电持续顶限、异常温升/异味、验收中反复掉线。不要盲目加大限流来"通过"。
- **官方 0.2 版图纸即无 CH340**（2026-10-26 核 BOM 关闭该出入）：早期调研"jyg9 版带 CH340"与官方图纸不符；USB 调试走 GD32 原生 USB（PA11/PA12）引到 H3 排针（GND/DP/DM/+BATT），成品板未引出 USB 座。台架上没有调试日志可看，判别全靠总线侧；固件升级后续走社区 `upgrade.py` 总线在线升级，本单不涉及。
- 出厂固件版本号未核（可在验收日志的应答包里找版本寄存器，或后续用社区主机工具读）；发现版本过旧再决定升级，不擅自刷写。
- 验收通过只证明"总线从站合格"；装入整机（挂 8.4V 总线末端、与 15 颗舵机同链 sync_read）按 [HAT 验证单](./hat-v1.2-test.md) 第 4 阶段整链通信执行。
