# 调研专题索引

本目录是**证据库**，不是教程。共 70 个专题（61 个现行、9 个归档），另有 1 份参考库导入记录。
先读本页的「说明」，再打开专题的 `research.md`；正文保留原始证据、勘误与未收口项。

- **现行**：结论仍可作为当前依据，引用前仍要看日期与勘误。
- **未收口**：问题没有最终结论，原文保留证据与下一步。
- **讨论稿**：流程或设计建议尚未确认，不代表已经实现或验收。
- **归档**：已被后续报告取代，只作历史追溯，不用于接线、下单或当前结论。
