## 推荐学习路径（建议，尚非批准设计）

建议使用嘉立创 EDA 专业版，自建可写工程；逐块理解参考电路并自己画原理图、布板。参考设计先核来源、许可和版本；不修改只读参考库。

1. 需求表：主控接口、输入电压范围、5V 供电需求、总线数量/协议、连接器、尺寸/孔位、保护与装配方式。电流指标需按实际负载和器件能力核算，不在本轮给出固定安数。
2. 框图：候选基础功能为电源入口、主控 5V 降压、UART 半双工总线与舵机/IMU 接口。额外 MCU、屏幕等暂不列为首版必需项；是否采用该范围待用户确认。
3. 选型与原理图：核器件数据手册、工作电压、引脚、封装及可贴装料号；逐块检查电源与收发逻辑，检查电气规则。
4. PCB：先定板框、安装孔与插座，再布局电源和总线；依电流、铜厚和温升目标决定电源走线，按芯片厂商布局要求处理降压回路；设置制造规则并执行 DRC。
5. 生产核查：检查封装焊盘/针序、主控对插方向、尺寸干涉、丝印与极性；预览 Gerber。DRC 仅按配置规则检查，不构成功能验证。
6. 导出：裸 PCB 为 Gerber 制造包（含钻孔/板框等所需数据）；SMT 另需 BOM 与贴片坐标，三者保持同一设计版本。归档工程源文件、原理图 PDF 和生产包。
7. 下单：上传文件、选 PCB 参数，选择是否 SMT；核贴装物料映射、方向、DNP 与自焊件，再核最终报价和审核反馈。价格/优惠/库存/交期以实际下单为准，本轮未查询实时报价。
8. 到货：按设计核极性与短路风险，HAT 单板限流上电确认 5V 轨，再接主控与单节点验证基本通信；带载动作前核保护位。若要验收整机再扩大负载范围，不直接做整机堵转。

装配建议：为走通一次功能板，可选 SMT 贴小器件、插接件自行焊接；最终按封装、器材和贴装支持确定。仅 PCB 打样不包含自动采购及焊接全部元件。

## 仿真能力补充（2026-10-28）

- KiCad 原理图编辑器集成基于 ngspice 的电路仿真，可进行工作点、直流、交流和瞬态等 SPICE 类分析；前提是器件具有可用的仿真模型，符号本身不等于模型。来源：KiCad Schematic Editor 文档的 Simulator、Assigning models、Running simulations 章节（https://docs.kicad.org/9.0/en/eeschema/eeschema.html）。
- ngspice 官方文档说明其输入是网表/模型并执行矩阵求解和仿真，因此仿真结果取决于模型、寄生参数和激励是否接近实物；不能把“仿真能收敛”当作整板可用证明。来源：https://ngspice.sourceforge.io/docs.html。
- 对本 HAT，可仿真的重点是 2S→5V/3.3V/1.8V 电源启动与纹波趋势、降压环路瞬态、背光/音频功率级、TTL 收发器方向切换和输入输出电平。BMI088、ToF、屏幕控制器、Radxa Linux 驱动、CSI MIPI 链路、机械装配和真实舵机总线协议不能只靠 KiCad SPICE 验证。
- 因此交付流程应增加“SPICE 可模拟模块报告”，逐项列出模型来源、激励、假设和未覆盖部分；同时保留 ERC、DRC、Gerber 检查和首板限流上电/功能实测。
