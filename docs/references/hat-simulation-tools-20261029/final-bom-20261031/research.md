## Signal Analysis Review

J502仍3.3V I2C扩展，不能连带5V上拉的模块。J504是10µF耦合的音频口，低阻耳机带宽仍未核准；播放主通路是PAM8302A→J506。J506两脚均为桥接输出，**都不是GND**。

SH厂商额定1A（AWG28条件）；理想2.5W/4Ω音频电流约0.791A RMS只是负载计算，不含未知扬声器、PWM/线缆损耗，也不是插座实测。EH的3A（AWG22条件）不默认覆盖15舵机动态峰值或更细线材。

## Power Analysis

计算脚本calculate_final_power_parts.py，结果power-part-calculations.json；**全为计算/假设，不是实测**。AP64350取RT200kΩ±1%对应450–550kHz，Vref0.8V±1%及两只1%反馈电阻，输出容差角4.852–5.119V。

在Vin=6.6/7.4/8.4V的分析窗口、最大3.5A负载、L=5.6µH×0.8容差×0.8额外偏置折减假设下，理想连续模式最坏电感峰值约4.135A，比IC最小峰值限流4.25A约低0.115A。该窗口不是新设电池截止电压；偏置折减是假设，厂商9A/20%下降为25°C典型值，不能说全温保证已通过。

电感DCR最大17.6mΩ@25°C、典型热电流9.3A/温升40°C、典型20%降感电流9A来自原厂p1；本板铜/气流/开关损耗不同。0.115A的限流余量较小，不能直接把3.5A芯片标称值写成整板连续额定。
