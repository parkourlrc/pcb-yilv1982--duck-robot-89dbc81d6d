## 一、Eq.12疑点已通过独立网络核对

依据为Diodes AP64350 DS41976 Rev5-2（December 2024）第17页图27/Eq.12及第18页选值方法。使用原厂[PDF](https://www.diodes.com/assets/Datasheets/AP64350.pdf)的既有归档，SHA和页码在datasheet-source.json；[原图裁片](ap64350-compensation-excerpt.png)已打开核对，未改原文。

先区分手册位号与本板位号：

| 功能 | 手册 | 本板 |
|---|---|---|
| 反馈上臂 | R1 | R301=52.3kΩ |
| 反馈下臂 | R2 | R302=10kΩ |
| COMP串联电阻 | R5 | R304=14kΩ，**不是本板R305** |
| COMP串联电容 | C5 | C301=3.3nF |
| 可选高频电容 | C6 | 本板未装此并联元件 |

按图示理想gm与无源网络，在前馈电容开路、无并联高频电容时：

\[
\beta=\frac{R302}{R301+R302},\qquad
Z_c=R304+\frac1{sC301},\qquad
-\frac{v_{COMP}}{v_{OUT}}=g_m Z_c\beta.
\]

**[推导/模型核对] 图27导出的系数应含反馈下臂R2，印刷Eq.12却使用补偿电阻R5。** 三组独立ngspice网络、每组301频点与推导的最大相对差<4.9×10⁻⁶；同时加倍两只反馈电阻、保持分压比不变时，理想电路响应不变，而印刷式变化6.02dB。本板参数代入印刷式会相对推导高约2.92dB。

这支持“印刷式与该图理想模型不一致”的判断，**不是厂商正式勘误或真实控制环验证**。各节点是小信号扰动，DC为0、AC=1用于归一化传递函数，不是给实物注入1V。模型没有功率级、采样/斜坡补偿、饱和、负载动态与寄生；1TΩ仅作DC数值参考。数据在compensation-check.json、compensation-ac.csv和spice/，脚本analyze_buck_compensation.py；[曲线](compensation-network-check.png)已打开检查。

图中0dB交点只是这个反馈/补偿网络的交点，不能当Buck完整环路交越频率；下节的一阶交越计算来自另一个选值关系，两者不能混读。

## 二、现有补偿值的设计依据与限制

R304/C301仍为14kΩ/3.3nF，与手册示例的补偿支路相同。按手册选值方法及名义参数，本地C305/C306在4.984V的典型模型合计33.244µF，对应补偿电容计算约3.381nF，现3.3nF有此名义选值依据；补偿零点约3.445kHz。

用手册名义gm=0.15mS、RT=0.089及明确电容/电阻情景，Eq.17一阶交越频率的最大计算值约28.5kHz，低于所采用450kHz开关频率下的1/10参考值。**这不是增益/相位裕量保证**：gm/RT未作全温保证边界，电容来自典型模型和明确降额假设，远端/主控电容不能全频直接并成一个节点。

因此，本轮没有发现需要因Eq.12歧义而改掉14kΩ/3.3nF的依据，保持原数值。也不再把“等待公式澄清/完整模型”作为唯一推进障碍；实际负载、启动/瞬态与热条件仍单独核查。手册示例的16.6kHz/81.6°不是本板结果。

## 三、电源预算收敛到具体条件

power-envelope.json按手册Eq.11作容量筛查。以下只举Vin=6.6V、Vout假设5.119V、L取+20%为6.72µH、允许偏移假设0.2V的情景：

| 电容口径 | 电容值 | 公式给出的阶跃筛查边界 |
|---|---:|---:|
| 本地C305/C306降额情景 | 21.725µF | 约0.978A |
| 本地C305/C306典型模型 | 32.358µF | 约1.194A |
| 本板5V电容全部理想合并、典型模型 | 50.428µF | 约1.491A |

这是**假设情景，不是额定电流、实测阶跃能力或Radxa合格阈值**。远端C323/C328和主控侧电容的实际阻抗会影响有效贡献；稳态总电流与阶跃幅度是不同量。当前仍没有取得Radxa GPIO 5V入口的明确允许窗口，不能拿通用4.75V猜作厂家门槛，也不据此断言板会复位。

输入必须同时承担舵机直通支路及5V降压输入。例如两路各3A、5V总负载2.5A、Vin=6.6V、效率假设85%，输入约8.228A，超过既有Samtec特定配对/两接点条件下5.7A的对照值。因此不能把端口目录电流相加后宣称整板能同时使用；5.7A也不是未知配对座、线束或本板的已核准额定。这个情景不描述本机15舵机实测耗流，不用于解释旧白板缺答故障。

现有5V静态容差/铜段压降的限定计算仍见[原预算](../five-volt-paths-20261031/research.md)。本轮不改变反馈比例，不虚设额定，也未因未测风险新增保险或配电采购。

## 四、输入与保护责任

[电源接口说明](power-interface.md)列出了J301全部针序和保护范围。原始本机CAD确认：从F元件面、40P排母在上观察，J301 pin1位于最右；pin1=VBATT_2S_IN，pin2=POWER_GND。丝印2S+、GND分别对应这两针，采用1.0mm/0.15mm文字规则。

初版文字在预览中较紧，后续只拉开位置；旧图j301-input-tight.png和原始Fab预览保留。现行[j301-input-final.png](j301-input-final.png)已打开，两个标识分开，未移动连接器或铜。接口文字不提供反接保护，也不是实物上电许可。

U301保护只作用于降压支路，R309铜跳线和D301 TVS不提供整板持续过流/反接阻断；本板没有设置2S电池专用欠压截止。+3V3由Radxa提供，U702再产生1.8V，不能预期不接主控的空板独立产生正常3.3/1.8V。USB/HAT并供仍不支持。

本轮复查BOM、PROGRESS、照片索引及保护专题，未找到足以核准当前电池BMS/线束的新增资料。这只保留为自设计HAT的保护/额定缺口，不把旧记录倒推成现行v2必须重新配电或新增采购，未操作任何实物。
