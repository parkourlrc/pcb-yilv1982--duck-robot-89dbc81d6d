## Radxa官方页面补查

来源：[Radxa ZERO 3 hardware interface](https://docs.radxa.com/en/zero/zero3/hardware-design/hardware-interface)，2026-10-31读取，定位为Power、Debug Serial Port、GPIO voltage及GPIO interface。另核[资源下载页](https://docs.radxa.com/en/zero/zero3/download)Hardware Design段。来源类别为厂商公开文档，不是本机实测。两页原HTML归档为radxa-interface-20261031.html、radxa-download-20261031.html；HTTP 200、URL、SHA及定位摘录见[external-source-probe.json](external-source-probe.json)。

1. Power段写USB-C 1供电、仅支持5V，建议5V/2A或更高供电能力；没有在该段给出输入电压公差。不能把建议电源的电流额定当成本HAT输入端的台架限流设定。
2. GPIO表将pin2/4列为+5.0V；GPIO voltage段3.3V/3.63V针对逻辑GPIO，不能当作5V电源针的允许范围。
3. Debug Serial Port段再次确认UART2_M0兼作默认U-Boot console；这支持首板草案先核实际占用的要求，不说明用户现行系统仍占用，也不授权更改bootloader。
4. 资源页同时列3W V1.11与V1.12 AIC8800版图纸，不能只由网页推定用户板版本。本轮不重新下载或声称逐页核验这些PDF。

检索`site:docs.radxa.com "ZERO 3" "4.75"`、`site:radxa.com "ZERO 3W" "5.25"`及官方GPIO供电资料，网页工具未给出可用的补充电压窗口证据；后续直接读取以上两个厂商页面成功。此前“工具未返回页面”的失败记录仍作为当时历史事实，现行证据缺口应表述为“成功读取官方页面，仍未取得明确电压窗口”，不能再说所有网页均不可访问。没有据此声称已搜遍所有资料。
