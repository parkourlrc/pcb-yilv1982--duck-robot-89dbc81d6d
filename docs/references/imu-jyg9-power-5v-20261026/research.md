# jyg9 imu_to_dxl（板②）BOM/原理图电源分析——5V 供电可否

调研日期：2026-10-26。问题：用户问"分析单口板的 BOM 和原理图，是否能接受 5V 的供电"。对象：**IMU 板②（单 3P 口，jyg9 / microduck-community-kit 成品版，GD32F303）**。本调研只读参考库与公开网页，未上电、未改参考库。

## 结论（先行）

1. **5V 供电不会损坏板子，但按官方设计 5V 根本不会启动**——此前"5V 可能点亮、记录现象即可"的待确认项至此定案。依据：降压芯片 EN 脚由 R3 100K/R4 30K 从 +BATT 分压（分压比 0.231），ETA2845 的 EN 上升阈值典型 1.5V，**冷启动需输入 ≥ 约 6.5V；已启动维持需 ≥ 约 5.93V**。5V 时 EN = 1.15V，芯片保持关断、3.3V 无输出。
2. **7.4V（2S 标称）/8.4V（满电）正常**：EN = 1.71/1.94V，裕量充足。jyg9 README 标称"6~24V"与 EN 门槛 6.5V 吻合（启动门槛取整）；芯片本体输入范围 5~38V（OVP 37.5V，绝对最大 42V）不是板级实际下限，**板级下限由 EN 分压决定**。
3. **CN1（JST EH 3P，2.5mm）针序 1=GND / 2=+BATT / 3=DATA 获图纸级确认**，与 2026-10-11 照片推断一致（图物对应仍待实物核对）。注意图纸还有并联的 **CN2（JST PH 3P，2mm）座，针序方向相反：1=DATA / 2=+BATT / 3=GND**——实物照片只见一个 3P 座，CN2 是否焊接待实物确认。
4. **板子没有真正的防反接**：电源正极路径上无保险/PTC（唯一 PTC F1 40Ω 在 DATA 线上）。反接时靠 D1 SMAJ24A 正向导通兜底，SMA 封装扛不住持续短路电流——**断电核针序仍是上电前唯一防线**（与现行验收单一致）。
5. 附带澄清：官方 0.2 版 BOM **没有 CH340**——早期调研"jyg9 版带 CH340"与官方图纸不符；USB 调试走 GD32 原生 USB（PA11/PA12）引到 H3 排针，2026-10-14 照片"未见 CH340"与此一致，该"出入"关闭。

### 3. 电源树还原（PCB 网表提取，10p 生产版）

```
CN1 EH(2.5mm) 1=GND 2=+BATT 3=DATA     CN2 PH(2mm) 1=DATA 2=+BATT 3=GND（并联，针序镜像）
+BATT ──┬── U1 IN(pin5)
        ├── D1 SMAJ24A（K→+BATT, A→GND）
        ├── C6 10µF/50V
        └── R3 100K ─ U1 EN(pin4) ─ R4 30K ─ GND      ← EN = 0.2308×VBATT
U1 SW(pin6) ─ L1 10µH ── +3.3V（C5 22µF + C20 1µF）
U1 FB(pin3) ← R1 75K(+3.3V侧) / R6 24K(GND侧)          ← Vout = 0.8V×(1+75/24) = 3.3V ✓
+3.3V ── U6 ME6211C18（CE=3.3V）→ +1.8VA ─ R32 0Ω ─ U3 LSM6DSV16X Vdd(pin8)
DATA ─ F1 PTC40Ω ─ D2 ESD ─ R5 51Ω ─ DATA1（U4 发缓冲 / U5 收缓冲，TXD_EN 方向控制，Q1 MMBT3906 + R29 20k 组成使能）
调试排针：H3 4P = GND/USB_DP/USB_DM/+BATT（GD32 原生 USB）；H2 5P 含 RST/3V3/GND（经 R14 1K）；H1 4P = 3V3/GND/预留
```

FB 反推验证：0.8V×(1+75/24)=3.30V，与实测设计 3.3V 完全吻合，佐证网表提取正确。

| 输入 | EN 分压值 | 判定（阈值 1.5V/滞回 1.37V） |

## 对整机使用的含义

- 板②挂 8.4V 总线末端的工作电压全程在 EN 维持阈值（≈5.93V）之上，正常。但若整机用到 6.6V 停机阈值附近，IMU 冷启动已不可靠（6.5V 门槛）；实际策略上低电量先停机即可，无需改硬件。
- 7.4V 台架验收流程（[docs/imu-gd32-bench-test.md](../../imu-gd32-bench-test.md)）不变，且本轮从原理上排除了 5V 试机的意义。
- 反接无保险：D1 正向导通是唯一泄放路径，SMA 封装持续短路会烧——**断电核针序（蜂鸣档）保留为上电前强制步骤**。
- H3 排针带 +BATT 裸针：台架/整机操作避免金属物触碰排针区。

## 验证状态与限制

- **本机实测：无**（纯图纸+手册分析，属"原理图或厂商规格"级证据）。
- 假设：用户成品板 = jyg9 官方 0.2_10p gerber 批次。若实物批次不同（例如改动 EN 电阻），结论需复核；上 7.4V 首次供电时若不启动，优先回读板上 R3/R4 丝印值。

- 调试排针 H1/H2 的信号映射未逐脚追查（与本调研主问题无关）。

## 追加（2026-10-26 同日）：改设计可行性——开关切换 5V/7.4V + 加中间节点 3P 口

用户问：能否修改设计，加开关在 5V 与 7.4V 间切换，并再加一个 3P 口支持串行总线中间节点。结论：**两件事电气上都可行，但"中间节点"有载流红线**；且重新打板有固件成本（见下）。以下为设计方案级分析，未动任何工程文件；实施 = 复制官方 KiCad 9 工程到本项目 `hardware/` 工作副本后改图重出 gerber。

### 1. EN 分压切换（支持 5V）——可行，两种接法

原理：把 EN 从"固定 6.5V 启动门槛"变成可选。5V 启动要求 EN@5V ≥ 1.5V ⇒ 分压比 k ≥ 0.30。

**方案 1（推荐，1 颗开关并联 R3）**：SW1（2 脚侧拨开关，如 MSK-12C02 类，或 2.54mm 1×2 跳线帽）并联在 R3（100K）两端。
- 断开 = 现状：k=0.231，冷启动 ≈6.5V（7.4/8.4V 正常，保留防深放电锁定）；
- 闭合 = EN 直连 +BATT：≥4.5V（芯片本体 UVLO）即启动，5V 可用。
- 合规性：EN 绝对最大 -0.3V~VIN+0.3V，直连合法；EN 输入电流 1~5µA，开关无额外损耗。

**方案 2（两级门槛都保留）**：R4 30K→47K（5V 档：启动门槛 1.5×147/47 ≈ 4.69V，5V 时 EN=1.60V，有 100mV+ 裕量），R4 两端加跳线并联 82K（闭合 = 47K∥82K ≈ 30K，恢复原 6.5V 档）。

**5V 档边界（两方案共用）**：ETA2845 规格输入下限 5.0V——供电须稳定 ≥5.0V（建议 5.1V 以上电源；USB 长线/劣质充电头会欠压）；5V→3.3V 占空比 66%（上限 99%），板上负载几十 mA，无压力。

### 2. 加 3P 口（中间节点）——电气可行，载流是红线

- **先查官方已有资源**：0.2_10p 图纸本就带 CN2（B3B-PH-K-S，2mm）与 CN1 并联在同一 +BATT/DATA/GND 网络——若成品板焊有 CN2（照片只见单 EH 座，待实物确认），配 PH 3P 线即可零改板获得"双口"。但 PH 与 EH 线不通用、且 CN2 针序与 CN1 镜像（1=DATA 2=+BATT 3=GND），改板时统一成 EH 更安全。
- **改法**：CN3 用 B3B-EH-A 并联 +BATT/DATA/GND，**针序与 CN1 完全一致（1=GND 2=+BATT 3=DATA）**。DATA 并联在 F1 PTC/D2 ESD 保护外侧；1Mbps 半双工总线多一个分接点无实质影响（板① ScrapMeta v0.3 即 J1+J3 双 EH 并联先例）。
- **⚠️ 载流红线（本轮 PCB 实测数据）**：+BATT 走线仅 0.3/0.5/1.0mm 三档（1oz 外层），持续载流约 0.7/1.2/2.5A；官方 README 定位本板"固定在电池背面"=**链末节点**，不是穿板配电件。若"中间节点"意味着下游还要挂舵机：舵机链峰值电流（2~4A 量级，EH 座自身上限 3A）会烧穿板走线。**可行用法：中间位置只作布线折返（下游不再接舵机）**；若坚持穿板带下游舵机，改板时须将 +BATT 穿板路径按 ≥3A 重设计（外层 ≥2.5~3mm 或双面铺铜 + 0.6mm 过孔缝合阵列，每安培 2~4 孔），且 EH 座 3A 仍是天花板。

### 3. 重新打板的连带成本（决策前必读）

1. 0402 阻容 30+ 颗 + SOT-23 封装——手焊不现实，走嘉立创 SMT（官方 bom.csv 已带 LCSC 编号可直接下单，[tools/jlc-order](../../../tools/jlc-order/README.md) 可用）。
2. **自产板没有出厂固件**：参考库 `firmware/v1` 只有源码（CMake 工程，无预编译 hex）——需 arm-none-eabi 工具链自行编译 + DAPLink/OpenOCD 烧录 GD32F303。这是一条完整的固件构建链，不是"买来即用"。
3. 改动需在 KiCad 9 中重新布局（开关、CN3 位置）+ DRC + 重出 gerber。

### 4. 不改板的替代路径（供权衡）

- 5V 需求若本质是台架供电方便：DLX-30V10AMF 可调电源直接 7.4V 即可（已到货）。
- 或 5V→8.4V 微型升压模块前置（几元级，不动设计）。
- 中间节点需求若只是物理布线：先确认实物 CN2 焊盘是否可焊。

**验证状态**：本节为设计方案级推算（芯片手册 + PCB 走线实测数据），无实物验证；5V 档参数未经样机确认，实施后需在 5.0/5.1V 实测启动与 1Mbps 总线通信。

## 追加 2（2026-10-26 同日）：HAT 是否同样有穿板风险；必须穿板时的设计规则

用户追问：要重新打板，HAT 上也是 EH 座，是否同样有风险；如果必须支持穿板走线怎么做。

### HAT 与 IMU 板的穿板风险性质不同（对照）

| | IMU 板（jyg9 imu_to_dxl） | HAT（V1.2 实物） |
|---|---|---|
| 穿板是否设计意图 | **否**——官方定位链末节点（README"固定在电池背面"） | **是**——两个 SERVOS 口同网直通，官方用法即"一口进电池、一口出整条舵机链"（[供电复核](../power-review-20261010/research.md)、[接线意向图](../../photos/hat-v1.2-wiring-plan.png)） |
| 供电路径 | +BATT 走线仅 0.3/0.5/1.0mm（1oz，≈0.7/1.2/2.5A 持续，本轮 PCB 实测） | **直通铜箔**，舵机大电流不经 5V 降压支路（[堵转风险核查](../stall-hat-risk-20261010/research.md) 已核 V1.0 路径）；**V1.2 实际铜箔规格未核**（图纸未取得，图物有差异） |
| 连接器上限 | EH 3P ≈3A/针 | 同 EH 3P ≈3A/针（待核系列适配：C001 规格书 AMP2.0-3P vs HAT EH 座，BOM 已有待办） |
| 已知电流事实 | 板自身几十 mA | HD-1910 单颗堵转 2A±10% @7.4V（厂商规格书）；15×同时堵转是极端算术非现实波形；本机正常步态总电流未实测 |
| 现行风险跟踪 | 本轮新结论：穿板带舵机=超设计 | stall-hat-risk 专题在案：无证据一次短时堵转烧板，但保护默认关闭、也无证据保护来得及；EH 座 3A vs 实际波形未测 |

**结论**：HAT 用作穿板**在官方设计意图之内**（社区整机同用法），不像 IMU 板那样超设计；但"官方这么用"不等于本机实测通过——3A 座上限、V1.2 铜箔规格、堵转 2A/颗这三项仍是现行跟踪中的开放风险，因此既有纪律不变：不做整机堵转、分级限流上电、带载后温升/压降作为排查项。全 15 颗堵转时 HAT EH 座电流的定量推算（算术极值 30A、计入回路阻抗约 15~20A）已追加至[堵转风险核查专题](../stall-hat-risk-20261010/research.md) 2026-10-26 节。

### 必须支持穿板走线时的设计规则（按 ≥3A / ≥5A 两档）

1. **先定电流预算**（不是"15×堵转"）：穿板电流 = 下游全部负载。现实预算取持续 2~3A（步态底流+单关节堵转）或 4~5A（多关节瞬时），尖峰毫秒级可放宽。
2. **连接器是硬上限**：EH/XH 均 3A/针，穿板路径 +BATT/GND 各走一针即上限 3A。要 5A 级需换 MX3.0 类（≈5A）或电池入直接 XT30，舵机侧仍受原线 3P 限制——**标准 3P 舵机线体系内，穿板件的实际天花板就是 3A**。
3. **铜箔**：外层 1oz 按 IPC-2221 10°C 升约 2.5A/mm——3A 取 ≥1.5mm、5A 取 ≥2.5mm，或直接 2oz 铜（打板加价低）+ 双面铺铜。
4. **过孔缝合**：0.3/0.6mm 孔约 0.5~1A/孔，换面铺铜必须打孔阵（3A ≥6~8 孔、5A ≥10 孔），瓶颈常在**座焊盘到主干的颈部**——铺铜直接包裹焊盘。
5. **验证**：样机用可调电源 CC 档阶梯通流，点温计看座子/焊盘/铜箔 10 分钟温升（≤20~30°C），并测 mV 级压降。
6. **拓扑优先于改板**：穿板点应只存在于**链头一处**（电池→HAT→第一颗舵机）；链中舵机间用舵机原线直串（每段电流自然只承担下游）；**IMU 永远挂链末**（几十 mA）。给 IMU 加穿板即使加宽走线，3P 体系 3A 天花板与多一颗插接件损耗仍在——若动机只是布线折返，优先调整链序/走线，而不是让小板承担配电任务。

**验证状态**：本节为设计规则级推算（厂商规格 + IPC 经验值），HAT 部分引用既有调研结论，无新实测；HD-1910 堵转 2A 出处为厂商规格书（[B 线 HD-1910 资料](../../../references/microduck-replica/tools/FeeTech_HD1910M_Servo/README.md)），本机实际波形待带载实测。

### A. 需用户拍板的设计决策

1. ~~中间节点的真实用途~~ **已拍板（2026-10-26 用户决定）**：IMU 板作串行总线的中间节点穿板带舵机——**两条腿支线（右腿 10-14、左腿 20-24）汇合接 IMU 口 1，口 2 连颈部舵机链（30-34）**；EH 座电流超载**接受不管**，过流保护方案后续另开专题。
   - 拓扑与电流账（推算）：穿板电流 = 颈部 5 颗 + IMU 自身（≈可忽略）。颈部 5 颗并联堵转阻抗 0.74Ω，计入回路阻抗 0.15~0.35Ω（HAT+腿链路径更长）：**全堵转穿板 ≈ 7~8A，算术极值 10A**——比 15 颗全穿板（15~20A）减半；正常步态颈/头/嘴瞬时 1~3A。EH 座 3A 额定超 2~3 倍，按用户决定接受。
   - 腿链尾段线缆与 IMU 口 1/口 2 针承载同上；HAT 出口段仍为全链电流（与现架构相同，未变化）。
   - **DATA 总线成树形分叉**（HAT→两腿→汇合→IMU→颈部）：鸭身内 stub 长度 cm 级，1Mbps 半双工 TTL 理论影响小，但上游真机只验证过纯单链——**改板后整链通信实测列入验收项**。

   - 协议层无碍：飞特 sync_read 按 ID 槽位应答，IMU ID 200 物理位置在颈部舵机之前不影响应答次序（位次仲裁已由 v1 固件处理并有真机验证）。

### A2. 穿板设计落地（决策 1 的实施含义，2026-10-26 补）

用户已接受 EH 座超载，但**重新布局时以下载流优化几乎零成本，建议顺手做**（不改变"超载先不管"的决定，只为多留裕量）：

- +BATT/GND 穿板路径（口 1→口 2 铜箔）尽量加宽（≥1mm，能到 2mm 更好）或双面铺铜 + 0.6mm 过孔缝合 6~8 孔；板厂选 2oz 铜加价极低。
- 口 1/口 2 焊盘铺铜直接包裹，避免颈部细颈。
- 目标不是 3A 合规（EH 座天花板仍在），是把板内铜箔从"最先烧的点"挪出名单，让瓶颈只剩座子本身（后续过流保护专题再收口）。
