# HAT报价差异与降本优先级

日期：2026-11-04（Asia/Shanghai）。用户问题：为什么两套报价相差很多、哪些可以优化。本轮只做报价归因与改进建议，不改CAD、物料匹配、订单或付款，不使用subagent。

## 依据与结论等级

- **[网页回执]** 使用本专题已经保存的2026-11-04 Y7/Y8订单、SMT物料行和费用明细；本轮没有重新锁价/锁货。PCB为已创建订单价，SMT为含缺料的草稿。
- **[计算]** `calculate-cost-drivers.py`按C编号合并重复显示行，不能将同一货号的总采购量在不同位号行重复计费。自主逐项合计1380.4755元，四舍五入1380.48；kissqy合计287.751元，四舍五入287.75，与两费用弹窗一致。
- **[限制]** 自主C301被分配私有库且库存0，未显示购买价格；3颗C308/C309/C328仍被错误映射Samsung X5R。故1380.48不是完整精确原BOM采购承诺。缺料项显示的是参考价格，改版必须重新计价。
- **[文件核对]** 制造源为86654c03的A.1，填孔清单在`hardware/custom_hat/order-submission/20261103-five-hats/via-process-requirements.csv`；唯一0.15mm孔属于U701.7，另5个0.3mm填孔属于U301散热焊盘。
- 本轮不是完整电气/DFM审查，不重复未改CAD的DRC/ERC/仿真；替代件资料沿用已归档原厂规格，尚未批准采购或装板。web公开检索及TI文档打开未返回可读内容，未声称本轮网上取得更新的厂商资料。

## 一、1915.71元差价如何组成

| 项目，5片 | 自主A.1 | kissqy | 差额 | 占总差价 |
| --- | ---: | ---: | ---: | ---: |
| PCB | 820.80 | 48.42 | 772.38 | 40.32% |
| SMT草稿元件费 | 1380.48 | 287.75 | 1092.73 | 57.04% |
| SMT草稿加工费 | 874.82 | 824.22 | 50.60 | 2.64% |
| 合计，不含最终运费 | 3076.10 | 1160.39 | 1915.71 | 100% |

**[计算] 元件与PCB占差额97.36%。** 物料数量不能解释价格：自主58件/板，kissqy86件/板；真正差在料号、采购数量/备损、制造选项以及功能不完全相同。两者codec为同型号，显示采购费用均74.70元/5颗，不是主要差价来源。

**[工程判断] 当前自主实现没有以低成本小批量作为已验证的优化目标。** 现货替代、局部布线能通过检查，与整套制造经济性是不同问题。当前高价料、唯一小孔及其关联制造选项已在真实网页报价暴露成本，不应继续只以“DRC通过/都有替代候选”为降本完成依据。

以上首四项在自主草稿占990.88元；只有母座、IMU等可明确对应不同设计功能/选型，不能将全部990.88都写成可省金额。电阻、小信号逻辑与大多数去耦的单项金额较小，优先级应低于高价电容和连接器。

原A.2候选是**保供方案**，还没有完成成本优化：例如AP64350参考10.62元换AP64351目录13.57元；原Vishay电感参考4.20元换M01目录12.16元。换为有货并不必然更便宜，旧方案仍保留0.15mm孔、6处填孔、内层1oz与沉金，所以不能预期其自动消除PCB高价。不同报价口径、缺货与温度/封装差异均需保留。

## 三、PCB：保留四层也能先做降本设计

Y7价格拆分中，以下选项合计**647.80元**。这是当前成本暴露金额，**不能直接相减承诺新版节省647.80元**，因为选项互相影响、0.2mm也可能有费用、报价起步价与可制造性需重算。

| 当前费用 | 本批金额 | 如何优化 |
| --- | ---: | --- |
| 0.15mm最小孔202.93＋关联四线测试100.78＋TG15520.29＋水平沉铜20.15 | **344.15** | 首先重做U701.7扇出，尽量移出焊盘，使用0.2/0.3mm常规孔路线；完成几何、回流和可制造性检查后重新报价。不能只把下单孔径选大。 |
| 过孔树脂填充/盖帽 | **101.46** | 不仅有codec孔，还有U301的5个散热焊盘孔。只改codec不能宣称整板不再需要填孔；须共同重做散热焊盘/过孔/锡膏安排，核散热与吸锡，再评普通工艺。 |
| 内层1oz | **100.49** | 评估采用工厂常规内铜并重新核电源/地平面压降和温升；大电流外层走线与过孔不能跟着无条件减铜。 |
| 沉金101.37＋大面积沉金0.33 | **101.70** | 评估OSP。kissqy在相近QFN/双面装配项目已得到OSP报价，但不等于自主板可直接沿用；需核铜面、存储/焊接流程与细间距焊盘。 |

**[建议] 第一轮保留四层，优先消除非常规工艺。** 改两层涉及更大范围布局/电源与I2S回流重做，当前证据不足以把它定为最划算的首步。适度增加面积只有在能换来常规扇出或更少装配面时才有成本价值；头壳/对插范围需一起核，不承诺65×30mm内必然能取消所有特殊工艺。

## 四、加工费：少量样板的装配路线

两套加工费只差50.60元，但各自都约八百元，说明这一批的主要直接差价不在加工。尚未拆出钢网/开机/换料/THT各子项，不把全部八百元都声称为固定开机费。

**[推断/建议]** 要进一步降低两套总价，评估单面SMT、减少不同封装/换料组数、连接器采用可由工厂后焊的工序。需要真实重新计价，目前不能量化节省。kissqy底面仍有J4排母，自主底面34件，现稿都不能直接在网页勾“只贴顶层”并称完成全装。纯粹增大采购数量只摊薄单价，不等于5块成品总开支更低。

## 推荐执行顺序与限制

1. 保留既定功能，优先完成22µF电容、40P母座和普通排针的低成本现货候选；把C301私有库与3颗KEMET误匹配一起纠正。
2. 另做局部布局候选：先U701.7常规孔，后评U301的散热/填孔；仍以四层为第一目标，复算回流/电源，不能仅改单参数。
3. 比较常规内铜与OSP对PCB报价的独立影响；每个候选重新生成对应制造文件后取报价，不删除实际设计仍依赖的工艺。
4. 再评LDO和电源器件成本；降压电流/峰值限流/热约束保持明确，不能直接借用kissqy的2A级电源换取原方案3.5A级器件标签。
5. 是否取消BMI088、是否扩大面积或改两层/单面SMT属于扩展范围；取得用户选择后更新方案，不默认为已批准。

截至本轮仅建议和计算落盘，无新的设计、订单或付款变更，也没有能据此承诺的优化后总价。
