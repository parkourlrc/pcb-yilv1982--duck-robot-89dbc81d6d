# HAT/Radxa名义板间距条件表

**D是两块PCB相向表面的距离。** 在已核较高器件的刚体包络和参考排针长度条件下，采用自选0.5mm几何余量，名义筛查范围为**11.6～13.33mm**。13.33mm已经在最小插深边界；所有公差、线束弯曲和附件加入后，可用范围会缩小。

| D | SSW排母名义插深 | J402含插头壳余隙 | HAT朝外J301裸针顶点距Radxa顶面 |
|---|---|---|---|
| 12.0mm | 5.01mm | 0.90mm | 21.95mm |
| 12.5mm | 4.51mm | 1.40mm | 22.45mm |
| 13.0mm | 4.01mm | 1.90mm | 22.95mm |

公式：插深=参考排针顶8.5+排母体8.51−D；目录插深要求3.68～6.35mm。J402名义余隙=D−8.1−3.0。J301朝外高度=D+HAT板厚1.57+针座总高8.38。

尚需加入的量：真实40P排针高度及排母尺寸公差、隔离件长度公差、J402线径/弯曲半径、散热器/CSI排线、头壳内部边界、外侧J301配对插壳和线束。上述最后一列不是总装高度，还须加Radxa背面突出量。

当前不指定隔离柱长度或螺钉。H1/H2排母附近保持≤4.5mm的圆形头部外包络限制，不擅用垫圈或超径六角件；具体紧固组合随目标间距确定。不要把两板强压到底作为定位方式，也不要靠拉扯连接器保持悬空间距。
