# HAT制造规格选择：本地设计基线

2026-11-02，源b610f1dcd136f6266f21e1568da76f2457573475137de31431d06c72c5eafc3a。以下是可审阅的设计选择，**不是订单、工厂接受、付款或制造放行**。完整机器可读项见manufacturing-spec.json。

| 项目 | 本轮选择及边界 |
|---|---|
| PCB | FR-4四层，单元65×30mm，双联85×82mm；标称1.6mm |
| 层叠 | JLC041611-7628设计基线，外35µm/内30µm，PP各0.203mm、芯介质1.030mm；公开成品1.57mm±10%，Dk/Df未取得 |
| 表面 | 沉金ENIG，绿色阻焊，白色字符；项目选型以支持平整焊接面，不声称实板表面质量 |
| 盘中孔 | 逐孔清单6处/单元（U301×5、U701.7×1）树脂塞孔+电镀盖帽；公开盖帽铜厚≥10µm，不能用普通盖油替代 |
| 孔 | 159PTH+4NPTH/单元，无盲埋微孔；U701.7机械孔0.15mm须保留，B铜盘0.25、另3层0.35mm |
| 其他via | 遵循提供的Mask层；如厂商只接受整批填孔，应核对所有孔清单和成本，不能把6项清单写成全板已处理 |
| 分板 | 2mm铣槽/邮票孔，8mm工艺边，双面3个全局Mark和4定位孔；不用V割 |
| SMT | 标准型双面，B面先回流、含L301的F面后回流，全部6件THT随后安装 |
| THT朝向 | J301在B面，其余5件F面；J301 B端子面pin1/2对应1:2S+/2:GND |
| 钢网 | 名义0.125mm；按本开口形状计算的0.66面积比上限约0.1294mm，实际加工公差/工艺需保持印刷能力 |
| 锡膏/回流 | 无铅免清洗为设计基线；具体合金/助焊剂/粒度及实际曲线未确定，不由文件推定炉温 |

U301四个1.45×1.10mm/R0.05窗为项目工艺选择，69.63%铜land覆盖；U701四窗、U702十六窗及BMI08881%保持。实际锡量、空洞、器件保持、湿敏/供料和SH回流应用条件在生产准备时确认；目前没有新板或批次材料。

公开规则依据：嘉立创国内PCB能力表允许沉金/绿色与0.15～0.55mm树脂填孔盖帽；SMT能力表支持标准型双面。资料已归档，不等于本包组合已被实际接单。本文件不能覆盖生产稿或实际收板检验，也不授权下单。
