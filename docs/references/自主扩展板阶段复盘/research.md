## 3. 做对了哪些事

1. **在可写工作副本中迭代，保留参考来源与许可。** 没有为了本机修复改写三个只读参考库；历史版和候选仍可追溯。
2. **修正真实的符号/封装/极性问题。** 已有复审记录包括单向TVS、UMW LDO专用脚号、时钟/连接器封装与THT阻焊开窗，而非只追求DRC数字。
3. **建立完整项目候选与原生核验。** 检查原有连接、固定机械坐标和规则身份；不靠缩小间距或删除原连接掩盖问题。
4. **从同一版本导出并关联订单。** 84362651的新Gerber、BOM和CPL对应Y10，旧Y9不再冒充新源费用。
5. **发现漏装与报价口径问题。** 仅顶层选项曾漏底面J101；目录净量与订单含备损数量、SMT小计与PCB/运费分别核对。
6. **保留原始证据和结论边界。** 图片、文件、失败原因及未确认项落盘；付款依据为用户确认，未声称已收货或成功运行。

## 4. 应改进的地方

| 本次问题/限制 | 影响 | 下次做法 |
|---|---|---|
| 完整工厂费用和装配条件到较后阶段才充分暴露 | 需要大幅降本及布局返工 | 架构/选料时先估全焊成本与工艺，布局前核关键限制；最终仍按同源文件询价 |
| 本地封装、通用库与原厂脚号/视角不总一致 | ERC或DRC通过仍可能存在实际引脚错误 | 对关键器件保存精确厂牌/后缀、脚位图及符号到物理焊盘的映射 |
| 自动路由未连接数、分析器评分与原生结果不同 | 可能错误宣告设计完成或修错问题 | 自动工具给候选和线索，原生保存文件、实际连通与原厂依据负责裁决 |
| 完整副本缺设置、无效DRU或生成失败后读取旧结果 | “检查成功”可能不是当前规则或当前板 | 绑定源/规则摘要、运行成功状态与输出身份；工具变化时验证规则确实生效 |
| 移动器件后旧铜及回流约束需要处理 | 解决占位问题时可能新增短路、断线或回流变化 | 先分析邻接和几何，按受影响网络重布，再比对原有连接与参考铜 |
| 焊接空间和治具费用被混在一起期待节省 | 名义距离改善未必消除100元治具费 | 分别确认插件焊接空间、保护遮蔽、夹持和收费触发，不提前计减免 |
| 843.29→853.29及“合并合同”标签容易引起误判 | 会把SMT费用当整单价，或猜新增服务 | 展开合并支付明细逐行相加；新增10元未给明细就保留未知 |
| PDF可核料号，但无方向图、逐行用量或费用归属 | 不能完成全部工厂审核或换料费归因 | 先用导出做全表核对，再针对缺失字段取最少量补充证据 |
| 截图过多、长附件混入内嵌图片及敏感参数 | 上下文膨胀、工具限制和归档困难 | 优先表格/JSON/PDF，必要位置才看局部图；原件本地、脱敏件入库 |
| 多处文档重复写“当前”价格和停止点 | 部分入口在已上传/付款后仍写旧状态 | 订单状态与模块入口作主记录；其他入口简短链接，历史段标日期与版本 |
| 用户接手操作后助手继续沿旧页面状态推断 | 容易安排重复步骤或低估实际进度 | 新截图/用户确认优先更新状态，不把未观察到的步骤补成已审完 |

以上是对已有过程的改进建议，不是重新开启设计审查。未对每个问题量化工时或损失，不能声称已测得某种工作流提升百分比。

## 5. 提炼后的流程与HAT目前对应位置

### 第一版成本为何过高：补充归因

2026-11-05用户追问“第一版成本过高的原因”。这里固定指第一轮取得完整装配范围报价的自主A.1／Y7（源86654c03，2026-11-04），不混用原Y6漏THT草稿、未实施A.2目录候选或已付款B版。

[历史页面记录＋计算] 5片草稿3076.10元（不含运费）＝元件1380.48＋PCB820.80＋加工874.82。其中元件和PCB合计2201.28元；对当时参考Y8的1915.71元差额，元件/PCB两项占97.36%，这个比例是“对比差额占比”，不是本单总价占比。源报告为[差价归因](../两套扩展板订单与报价/cost-optimization.md)的第一至四节及[订单原记录](../两套扩展板订单与报价/research.md)。

1. **选料成本集中在少数高价件。** KEMET 22µF电容按网页备损29颗×15.52＝450.08元；Samtec40P母座5×48＝240元；BMI088芯片5×40.50＝202.50元；LP38691 LDO 5×19.66＝98.30元。四项合计990.88元，另有Samtec三组排针70.355元。数额对应当时采购/备损口径，不是今天报价；不能把全部金额都当可省。BMI088属于当时已确认的功能范围，后经范围调整取消，不能事后称其无需求。
2. **PCB实现叠加了非常规制造选项。** A.1采用4层、沉金、内层1oz、最小0.15mm孔及6处填孔盖铜；制造清单中唯一0.15mm孔在U701.7，另外5处0.3mm填孔在U301散热焊盘。旧费用归因记录小孔及关联测试/板材/沉铜344.15元、填孔相关101.46、内铜100.49、沉金相关101.70，合计647.80元。项目相关联、报价需重算，不等于逐项删除可直接省647.80，也不能把820.80全部归因四层。
3. **5片双面SMT并含THT的完整加工支出较高。** 加工874.82元，但参考Y8也有824.22元，差额仅50.60。因此小批全焊解释了两者的加工基数，不能解释自主版本大部分额外差价；并非874.82全是固定开机费。
4. **成本约束介入晚于部分设计决策。** [工程判断／推断] 从费用暴露后才系统调整高价料、工艺与布局的过程看，早期没有充分验证“必要功能/性能—可采购料号—布局工艺—小批全焊预算”的共同可行性，容易把局部可用、DRC可过或有货误当整板方案经济合理。记录支持这一流程解释，但没有逐项设计决策工时或对照实验，不能精确分摊返工责任或损失。另有当时功能需求更广、供货时点与备损计价的真实影响，不把所有高价都归为无必要的过度设计。

**数据限制：** 第一版1380.48元包含欠料参考价及3颗电容错误匹配，C301还被分到0库存私有库；3076.10不是精确原BOM全部可供货的最终成交价。错误匹配是报价可靠性问题，现有证据不能据此将它称为高价的主要成因。两版codec同型号、当时计价相同，也不是主要差价来源。

**流程上的直接改进：** 下次在关键选料和布线前加入全焊成本/制造约束检查，优先核高金额物料、最小孔及焊盘内孔、两面装配和治具；性能必要性与兼容性验证仍须保留。不以直接删功能、改单参数或未经核准替代料来假装降本完成。本次只解释历史原因，线路继续暂停。
