## 观察与待验证解释

1. [实测，训练日志] 第 1 至 22 更新，最近 100 个已结束回合的平均长度由 51.12 步增至 256.38 步（50 Hz 下约 1.02→5.13 秒），两端均为 100/100 提前失败；这是随机探索训练回合，不等同确定性开发评估。第 22 更新 raw 动作裁剪率 0.5088%，策略 std 0.32063；尚无昨天后期近乎全裁剪现象。
2. [源码核验] `locomotion_train_cfg.py:ppo_config` 的学习率调度为 adaptive，初始 3e-4 不代表全程固定。第 22 更新日志学习率 0.01。因此日后比较固定学习率需另列实验因素，不能仅设置初值后写成“固定”。
3. [源码核验] `locomotion_env.py` 的平滑项为 `-0.05*clamp(mean(delta_action²)/0.01,max=1)`；动作字段 `actual` 是限幅后的归一化目标，**不是实际关节测量角度**。训练日志的平滑损失接近饱和值，单纯增大权重可能仍然不区分不同高频动作。候选必须观察是否改变罚项饱和，不能只看权重变大。
4. [假设，机理示意] 若忽略惯性、接触、摩擦及力矩限幅，将 Kp=25、Kd=2 近似为一阶位置响应，时间常数 Kd/Kp=0.08 s，9.9 Hz 正弦目标幅值比例约 `1/sqrt(1+(2*pi*9.9*0.08)^2)=0.197`。这能提出“高频目标被慢响应衰减”的待验证方向，**不是拟合模型或已确认根因**。本机真实仿真具有惯性、接触和 ±0.94 N·m 限幅；这些替代解释未排除，须由子步 q/qvel/力矩与接触记录区分。

### 新回放的摆幅与脚底几何

[实测] `straight_0.06_101` 独立回放完整 23 秒，actor/归一化未变化。稳态统计实际时间 3.02–23 秒，峰峰值为该时间段极差，**不是逐步摆幅**：

| 关节 | 目标峰峰值（°） | 实际峰峰值（°） |
|---|---:|---:|
| 左髋俯仰 | 4.97 | 2.48 |
| 左膝 | 8.05 | 1.54 |
| 左踝 | 16.76 | 2.52 |
| 右髋俯仰 | 7.52 | 3.49 |
| 右膝 | 6.59 | 3.85 |
| 右踝 | 13.06 | 2.59 |

- 稳定段平均机体系前速 **0.006071 m/s**，目标 0.06 m/s；最大倾角 7.24°。
- 左/右脚碰撞盒最低点最大离地 **0.084 / 0.699 mm**，两脚超过 2 mm 或 3 mm 的采样比例均 0。最小值约 −1.03/−0.81 mm，模型软接触存在轻微穿透，不能把负高度解读为真实脚底穿地。
- 左/右踝目标频谱主峰 **23.05 / 23.35 Hz**；目标去均值信号中 >5 Hz 能量比例 **99.40% / 97.57%**。不是全部关节都同频，部分关节有低频姿态漂移；采样 50 Hz，接近 Nyquist 的主峰须结合子步诊断解释。
- 确定性动作最大绝对值 **0.59081**，raw 越界比例 **0%**。这排除了该回放由 raw 饱和裁剪直接导致小摆幅的解释；不能排除目标关节限位、PD/力矩限制和接触影响。

[推断] 小摆幅不是旧 10 fps 视频混叠造成的纯显示错觉；新 50 Hz 轨迹也存在实际小摆幅与极低脚底离地。高速踝目标与较小实际响应是可继续诊断的现象，不能直接认定调小阻尼或增加动作尺度即可解决。新旧模型来源/训练条件不同，不能把上述差异当参数消融效果。

### 评估与独立回放的重复性限制

dev9 的 0.06/101 场景 RMSE=0.054064 m/s、最大航向偏差约 33.00°；独立回放分别为 0.054182 m/s、38.49°。两者均完整且未达标，但数值并非逐位重现。[权重核验] 评估前与最终 checkpoint 的 actor 全部张量逐项相同，见[比较记录](amplitude-20261107-baseline/actor-equality.json)，排除了两份策略权重不同。必须分别引用，不能把 dev9 的航向数值写入回放统计。[待确认] GPU 物理重复性、独立回放进程计算设置等差异尚未分离，后续候选统一使用同一诊断入口并重复种子核查。

## 当前限制及下一步

新第 100 轮权重与评估已经保存，摆幅问题仍在。现有回放只记录 50 Hz qpos/动作及 500 Hz 根部物理轨迹，未记录子步关节力矩/接触力；脚底几何离地不能独立证明是否承重或打滑。同日后续已获批准并加入子步响应诊断，单因素比较滤波、平滑约束、阻尼，进展见[参数对照记录](百轮参数对照-20261107.md)；不修改物理质量、惯量、摩擦和力矩上限。本页记录基线完成时的结果；后续独立实验已执行，现行训练源保持原样；未提交或推送。
