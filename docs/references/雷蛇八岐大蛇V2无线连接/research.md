# 雷蛇八岐大蛇 V2 无线连接方式调研

- **日期**：2026-11-09
- **问题**：Razer Orochi V2（八岐大蛇 V2，RZ01-0373）连接电脑，是否必须占用一个 USB 口插接收器？
- **范围**：只确认连接方式与是否占 USB 口；不涉及驱动安装、按键自定义、游戏性能对比。
- **对象**：用户自述型号 "orochiv2"；本机无实物核对，以下结论不构成对本机设备状态的确认。

## 结论（速览）

1. **不是必须**。Orochi V2 是双模无线鼠标：2.4GHz Razer HyperSpeed（需随机附带的 USB-A 接收器）与 Bluetooth 5.0。**用蓝牙模式时完全不需要接收器，不占 USB 口**；用 2.4GHz 模式时才必须插接收器，占用一个 USB-A 口。
2. 该鼠标**没有有线模式，也没有充电口**，靠 1 节 AA（5 号）或 AAA（7 号）电池供电（二选一，不能同时装）。所以"占不占口"只取决于选哪种无线模式，与充电无关。
3. 续航标称：2.4GHz 约 425 小时、蓝牙约 950 小时（AA 锂电池、官方标称）。蓝牙模式更省电、适合办公/便携；延迟与回报率低于 2.4GHz，高要求竞技场景仍建议 2.4GHz。
4. **省口的前提是电脑自带蓝牙**。多数台式机没有蓝牙，需另插 USB 蓝牙适配器——那就同样占一个 USB 口；笔记本一般自带蓝牙，可直接省口。
5. 若只是 USB 口紧张但电脑有蓝牙：优先用蓝牙；若必须用 2.4GHz，可把接收器插到 USB Hub、显示器 USB 口或扩展坞（逻辑上仍占一个口，只是不占主机面板口）。接收器不用时可收纳在电池仓旁。
