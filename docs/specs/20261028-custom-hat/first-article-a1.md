## 2. 防烧板前置与第一步

1. **断电核对版本、针序和极性。** J301.1=2S正、.2=GND；.3=5V输出、.4=主控提供3V3、.5=NC、.6=1V8、.7=SERVO_VBAT、.8=GND。不能把8针当同电压排针。J101按实际pin1对插，不由观察方向猜针号；J502仅A.1为1GND/2VCC3.3/3SDA/4SCL。外接线束逐针核对应；明显焊桥/错装先处理。
2. **只保留空板5V轨这道前置实测。** 在第1节供电条件落实后，不插Radxa和外设，断电夹好绝缘测试夹，再按记录的设定限流供电。测J301.3对J301.2的5V并记录实际电流/限流状态，使用已落实的判定范围。不以裸表笔跨扫相邻针脚；异常电压、持续限流或异常发热即断电排查。
3. **断电后对插主控，再进入所需功能。** 主控只从HAT 40P取电。USB供电/刷写时断开HAT供电连接，不能只关闭电池开关后继续带电双源连接。空板没有独立3V3，1V8也依赖主控3V3，因此未插主控时不要求这两轨正常。

[文件/计算依据] Buck名义值4.984V，一阶参考/电阻容差估计4.852～5.119V；它是计算边界，**不是Radxa验收窗口或实测**。电源路径、保护职责及公式分别见[接口说明](../../references/hat-simulation-tools-20261029/power-acceptance-20261031/power-interface.md)和[5V分析](../../references/hat-simulation-tools-20261029/five-volt-paths-20261031/research.md)。TVS、R309铜跳线和Buck自身保护不等于整板反接、持续过流或2S电池欠压保护。

## 3. 功能验收：直接验证实际用途

| 功能 | 首次实际验证与合格证据 | 失败后才做的定位 |
|---|---|---|
| 主控及供电 | 已核输入条件下正常启动；记录所接负载、启动/复位现象。载流结论只覆盖此次条件 | 查带载5V、接点/地回程、3V3/1V8、限流和异常温升，不预设为某种机理 |
| 板载BMI088头部IMU | 按[适配器说明](../../../hardware/custom_hat/software/imu/README.md)核当前总线，双ID正确、配置回读、六轴数据会随实际运动变化；保存原始记录 | 查地址/占用/供电/接触；100Hz只是初始诊断配置，不当实测采样率；不替代TTL身体IMU200 |
| 播放/录音 | 先核实际内核/DT与声卡，再按[路由说明](../../../hardware/custom_hat/software/codec/AUDIO-ROUTING.md)低音量验证J506播放和J505录音；保存路由读回和PCM文件 | 查复位/时钟/I2S及模拟信号；只识别到0x18或声卡不算音频通过 |
| TTL总线 | 核UART2/调试console占用、方向GPIO和现行舵机协议后，先做目标设备身份/状态读取；通信通过与动作通过分开记录 | 查方向时序、波形、供电/地及接触；不加UART回环，不默认接全舵机动作 |
| J502扩展/ToF | 有明确3.3V模块和线束后核地址/上拉，实际读取模块数据；ToF则留测距数据 | 只有连接座不能声称完成测距；模块未选时记录“未测，外设条件未落实” |
| 安装与温升 | 实际堆叠无顶碰、错位；在已明确的负载下记录供电和发热异常。整机载流/热结论需要对应负载数据 | 功能失败或明显发热再定位，不以手摸温度或自动thermal分数签整板合格 |

J506是桥接扬声器输出，两脚都不能接地；扬声器实际阻抗/功率须在使用前核准。J504现有交流耦合口的低阻耳机用途未确认，不作为已承诺性能测试。舵机带载动作属于后续操作，恢复扭矩前仍按现行规则回读保护位并核对零位/目标。

## 4. 最小记录与判定

每次仅记录实际做过的项目：日期、板号/版本、源/软件身份、装配差异、供电设定与限流、外设/负载、5V实测、功能原始输出及异常。保存到本专题关联的首板实测目录，照片登记到[照片索引](../../photos/README.md)。现阶段不创建虚构的实测值或“通过”记录。

各项使用“通过 / 失败 / 未测”，并注明验证条件。通过某项功能不推广为最大额定、EMC认证、所有模块兼容或整机动作通过。测试异常先停受影响的通电/动作，记录现象；原因仍用[推断]/[假设]表达。纯软件回环、无目的I2C全地址扫描和额外静置测试不列入必做步骤。
