# Rev A 制造前条件（2026-10-29 修订）

**当前不能下单。** 主 PCB 有实验性布线，`U701.7` 的 `+3V3` 仍未连接；`kicad-happy` 还发现 MPN、fiducial、环宽、热过孔、via-in-pad、I2C 上拉和平面回流缺口。当前 Gerber/BOM/CPL 仅为[生产审查包](../../hardware/custom_hat/rev_a/production-20261030-review/README.md)，不是放行包。现状见 [kicad-happy review](../../references/hat-simulation-tools-20261029/kicad-happy-review-20261030/review.md)，执行顺序见 [修复方案](recovery-plan.md)。

必须完成：

1. AP64350/BMI088 真实符号、焊盘、方向及逐针对应；TTL、动力电源、音频播放/录音链完整；EH 与 40P 视角明确。
2. 完整功能布局、电源回路/地平面/扇出落实；TP802 原点问题已修，不重复列为未完成。
3. 同版本 ERC、重铺铜后 DRC 和原理图一致性核查；无未解释的真实连接、短路、板边或间距问题。
4. 锁定器件完整型号、LCSC 编号、封装、库存、DNP、自焊件和双面装配方向；不按旧 BOM 直接回填下单。
5. 确定板框/厚度/对插高度、铜厚、线宽间距、过孔、表面处理和钢网。4 层/65×30/外层2 oz 是方案起点，不是制造放行；AP64350 推荐外层2 oz，载流仍须逐路径核算，旧0.6mm≈3.3A已勘误。
6. 由同一通过审查的源版本重新导出 Gerber、钻孔、BOM、CPL、装配资料和源指纹，在制造预览核方向/原点/器件对应，再按用户要求办理订单。

首板上电只采用届时修订并核准的测试单。当前旧 [测试草案](first-article-test.md) 标为停用，不作为接线操作依据。没有付款或上传授权变化。
