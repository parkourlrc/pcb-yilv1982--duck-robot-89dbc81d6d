## 本轮确认改进的流程

详细方案与验收见 [workflow-improvement.md](workflow-improvement.md)。

1. 完整副本包含工程设置、规则、原理图和库；记录源指纹、工具版本、执行命令。
2. pipeline 默认检查副本，不重建主 PCB、不自动补孔、不放宽规则。
3. 自动路由显式请求、独立目录；校验 DSN/SES 本次产生、返回码及导入结果，失败不覆盖。
4. 原理图导出网表是连接核对依据；停止旧双来源生成器默认改板，契约仅用于比对期望。
5. 分别记录违规、未连接、一致性；每次新报告，命令失败即报失败，不拿旧报告凑“通过”。
6. 现行入口只留确认问题；历史记录保留并标出适用状态。
