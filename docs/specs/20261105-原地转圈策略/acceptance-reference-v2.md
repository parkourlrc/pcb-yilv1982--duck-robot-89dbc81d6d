# 联合策略验收参考值 v2.1

日期：2026-11-05。依据用户“补前进速度上限及行走、减速、转弯验收，你来推荐”，给出可用于后续方案的首版参考值。所属[任务定义](task-definition.md)。**所有新增数值为设计建议，未训练/实测验证，不是厂商能力或实物安全限值，也不冒充用户逐项确认。** 已确认的单模型、仅前进、61维、±30°/s及原地5 cm边界保留。

## 1. 命令范围与平滑

| 参数 | 首版推荐 |
|---|---|
| 前进速度请求 | 0～0.10 m/s，即0～10 cm/s |
| 验收前进档位 | 0.03、0.06、0.10 m/s；0另验停止与原地转 |
| 横向速度命令 | 恒0，不训练后退或侧移命令 |
| 偏航转速请求 | −30～+30°/s；弧线测±15、±30，原地另含±5 |
| 前进命令加速斜率 | 最大0.05 m/s²，0到0.10命令用2 s |
| 前进命令减速斜率 | 最大0.10 m/s²，0.10到0命令用1 s |
| 转速命令斜率 | 沿用30°/s²；+30到−30命令用2 s |

选择0.10 m/s是首轮缩小搜索与调试范围的工程取值，便于覆盖低/中/高档，不基于本机已验证最大速度。0.10 m/s按0.10 m/s²线性减速到0，**命令积分**为0.05 m；这里只解释时间/距离量级，不预测机器人真实制动距离。旧walk配置0.4 m/s不能作为本机达标依据。加减速及转向同时更新，允许减速保持非零wz。

## 2. 测量定义

- 平地、普通足部，从HOME站姿起步，单一模型连续运行；reset只在回合边界。每档3个固定种子0/1/2，沿用初始关节扰动±0.005 rad并受限位约束，根姿态/速度固定基线。
- 实际速度取仿真`trunk_base`原点世界XY速度，旋转到当前heading定义的水平前向/左向坐标系，得到前向/侧向速度；不能把含机身倾斜的局部速度未经说明当作水平速度。heading展开差分计算偏航转速，沿用0.2 s因果均值。
- 跟踪指标的线速度也用0.2 s因果均值（50 Hz下最多10个已有样本，不填假零）；窗口跨命令/行为切换保留。停稳则平均每样本水平速率的非负模长，不能先平均向量再求模而让往返运动抵消。
- 稳态跟踪对比用户请求，过渡跟踪对比同拍的斜率受限下发命令；两种数据均记录。滤波后指标合格不代表没有高频振动，原始速度与目标动作变化保留日志。
- 位置偏差、路径长度、失稳和接触异常按物理子步记录；时间使用仿真时钟。轨迹长度为相邻世界XY位置差的模长之和；漂移为相对固定锚点的最大径向距离，两者不混用。

## 3. 行走与转弯验收

| 项目 | 推荐通过条件 |
|---|---|
| 持续直走 | 每档3 s启动+20 s有效稳态；不能拼接reset回合 |
| 前向速度跟踪 | 稳态RMSE≤max(0.005 m/s,目标速度×20%)，3/6/10 cm/s档分别≤0.6/1.2/2 cm/s |
| 直走方向/进度 | 稳态≥95%样本前向速度为正；稳态沿起始前向投影的净位移≥目标速度×20 s×80% |
| 直走横向偏差 | 含启动的全段，相对初始heading直线的最大横向距离≤5 cm；这是新增建议值，和原地5 cm是两种指标 |
| 直走朝向 | 含启动的全段，相对起始heading的最大偏差≤10° |
| 侧向运动 | 直走/弧线稳态的侧向速度RMSE≤0.01 m/s |
| 弧线行走 | 每个前进档×±15/±30°/s，3 s过渡+20 s稳态；前向跟踪沿用上式 |
| 弧线转速 | 偏航转速稳态RMSE≤max(1°/s,目标绝对转速×20%)，15/30°/s对应3/6°/s |
| 弧线方向/进度 | ≥95%稳态样本转速方向正确，展开heading同向净增量≥目标绝对转速×20 s×80%；前向速度≥95%样本为正，前向速度积分≥目标前速×20 s×80% |

弧线不按世界直线横向5 cm或原地5 cm验收，不要求精确跟踪几何圆轨迹。这里约束速度、方向和侧滑；若日后需要指定路径，另立路径误差定义。

## 4. 减速、停稳及连续过渡

| 项目 | 推荐通过条件 |
|---|---|
| 前进/转向改变的响应 | 请求后3 s内进入对应稳态误差容差带并保持≥0.5 s；减速到0使用下列停稳判据 |
| 平移停稳 | 请求vx=0后3 s内完成：0.2 s均值水平速率≤0.01 m/s，倾角≤15°，机身roll/pitch角速度的0.2 s RMS分别≤15°/s，上述同时连续保持0.5 s |
| 转动中的停稳 | 保留非零wz时，偏航速度不要求归0；只检查平移与倾斜/晃动，允许边减速边转向 |
| 减速距离 | 从vx降零请求到停稳确认，实际XY累计路径长度≤0.15 m（15 cm）；同时报告最大径向位移，不用终点误差代替路径长度 |
| 原地锚点 | 移动入口在停稳确认时记录一次固定XY；后续起转/转向反转/停止保持累计最大漂移≤5 cm。静止起转验收从初始时刻记录，不等转动后再建立锚点 |
| 完全停止 | vx=wz=0请求后3 s内满足平移停稳，并有abs(滤波偏航转速)≤3°/s连续0.5 s；随后保持至少5 s，持续满足停稳速度/姿态条件与原地5 cm |
| 实际运动平滑 | 命令变化后的前3 s，滤波水平速度向量差分的加速度模长≤0.30 m/s²；滤波偏航转速差分≤120°/s² |
| 过渡跟踪 | 同一前3 s，前向速度对平滑命令RMSE≤0.03 m/s，偏航转速对平滑命令RMSE≤8°/s；不替代之后稳态判据 |

停稳窗口的0.5 s计入3 s总期限。若信号失效，不把填零速度视为满足条件；若3 s内不达标，场景失败，不靠无限等待建立锚点逃避判据。真值判据先用于仿真能力验收；独立估计器的误差/延迟须与这些目标对照，未验证前不能宣称实物门控已满足。

0.15 m减速距离及其余新阈值是首轮参考。若训练失败，先区分估计/模型/奖励/能力问题，参数变更须记录原因，不能默默放宽用户已定5 cm。

## 5. 全程失败与评估集

沿用原失稳参考：倾角≥45°、躯干原点高度<0.6×HOME高度或任意非足部碰撞体接地均失败；NaN/Inf、异常提前终止/截断/reset也失败。15°是建议停稳条件，45°是全程失稳边界，两者作用不同。对各项逐一判定，不能用平均奖励或平均成功率代替。

| 组 | 场景数（每种3个种子） | 覆盖 |
|---|---:|---|
| 原地子集 | 8 | 沿用v1的6个恒转速、零速保持、双向反转/停止完整场景；每个恒速60 s稳态 |
| 直走 | 3 | 3/6/10 cm/s，3+20 s |
| 弧线 | 12 | 3个前速×4个转速，3+20 s |
| 连续过渡 | 6 | 3个前速×初始左右转向；直走→弧线→减速持续转向→原地转→恢复前进→行走中反向转弯→完全停止 |
| 直走停车 | 3 | 3个前速直走后vx/wz均0，验证没有转向时的停车 |

共32种×3种子=96回合，属于正式仿真验收参考集，不要求每轮训练都执行全量。连续过渡建议时间：直走23 s、弧线13 s、减速最多3 s后原地保持60 s、恢复前进同向弧线13 s、反向弧线13 s、全停最多3 s后保持5 s；每段保持同一模型及状态，任一阶段失败即本回合失败。入口步态由连续运行自然产生，不声称3个种子覆盖全部步态相位。最大预期133 s，评估环境上限应长于此值，不能沿用旧90 s上限；训练回合时长另在第③/④步设计。

96回合全部通过才称本参考集通过；仍不代表连续速度域全覆盖或实物通过。初期可运行子集诊断，但须报告覆盖范围。曲线行走与减速距离只在本平地/无推扰条件评价。
