合计61，恒零命令11个。actor/critic首版均61维，无历史堆叠或特权输入；位置、接触、速度真值和锚点状态仅供奖励/统计。新训练单独建立归一化，导出内嵌一次，部署不能再次归一化。

显式关节顺序：`left_hip_yaw,left_hip_roll,left_hip_pitch,left_knee,left_ankle,neck_pitch,head_pitch,head_yaw,head_roll,right_hip_yaw,right_hip_roll,right_hip_pitch,right_knee,right_ankle`。解析joint/actuator ID后逐项比对，不能依赖正则或资产内部顺序。

动作参考：先拒绝NaN/Inf，再 `a_clip=clip(a_raw,-1,1)`；`q_target=clip(HOME+0.5*a_clip,joint_lower,joint_upper)`。0.5rad是用户确认采用的设计初值，原walk缩放1.0不能混称相同接口。保存`a_raw`给下一拍观测，同时保存`a_actual=(q_target-HOME)/0.5`给平滑奖励；两者分开。reset两种历史均置0，行为变化不清历史。

## 3. 联合命令与连续轨迹

请求值与给策略的斜率限制值分开。范围vx=0～0.10m/s，vy恒0，wz=±30°/s；前进加速0.05m/s²、减速0.10m/s²、偏航变化30°/s²。停车计时从请求vx变0开始，允许减速时wz保持非零。数值为第②步参考，不代表实机已达能力。

训练reset按回合选择轨迹族：原地长段25%、直走20%、弧线25%、联合连续25%、零速保持5%。原地段为3s启动+60s恒速、反向13s、全停8s（84s）；直走为23s+全停8s（31s）；弧线为23s、反向13s、3s减速、60s原地、8s全停（107s）；联合为23s直走、13s弧线、3s减速、60s原地、13s恢复弧线、13s反向弧线、8s全停（133s）；零速20s。轨迹段只变命令，不reset物理或历史。

直走/弧线/联合族的vx：50%选择0.03/0.06/0.10m/s，50%连续采样[0.01,0.10]m/s；弧线wz左右等概率，幅值15/30°/s。原地长段族wz独立选择左右（各50%），幅值50%均匀选5/15/30°/s、50%连续均匀采样[5,30]°/s；反转段保持幅值、符号取反，由同一偏航斜率限制器减速过零。训练3s减速未停稳仍保持vx请求0；达到6s未停稳终止。正式评估使用第②步96回合固定场景/种子，不能用训练随机比例替代覆盖表。

## 4. 锚点状态与停车边界

状态是环境内部逐环境统计，不切模型、不新增actor输入：

1. reset且vx=0立即记录躯干XY初态，进入`anchored`；首段前进进入`moving`。
2. 任意状态收到正vx结束当前原地片段进入`moving`，不重置其他历史。
3. `moving`首次收到vx=0进入`braking`，锁存开始时刻/位置，累计实际XY路径；重复零命令不重启计时，偏航变化不重启。
4. `braking`满足停稳条件连续0.5s进入`anchored`并记录锚点：0.2s均值速率模长≤0.01m/s、倾角≤15°、roll/pitch角速度0.2s RMS各≤15°/s；不要求偏航为0。
5. `anchored`中反转、停转均沿用锚点；超过5cm锁存严格失败，训练探索边界20cm，不能重锚掩盖失败。该边界不用于正常行走或减速出生点。

请求停车3s未确认停稳即锁存严格失败；训练可继续至6s，3～6s增加超时惩罚，6s仍未停稳才终止。迟到停稳可建立训练锚点但不清除严格失败。缺测/非有限速度不能按0处理。

完全停止使用独立时钟：任意状态首次收到请求`vx=wz=0`时启动，包含已anchored的转圈状态；重复零请求不重启。要求平移停稳条件与实际偏航速率绝对值≤3°/s同时连续满足0.5s，且确认时刻不晚于请求后3s（3s包含这0.5s）。超时锁存`strict_full_stop_timeout`，与平移超时分别记录；训练可继续至6s，仍未确认则终止。确认后另开5s保持窗口，所有停止条件须持续满足，任一违反锁存`strict_full_stop_hold_failure`；不能重启保持窗口补救，训练仍记录失败且保留原时间线。该时钟和保持窗口均不重建XY锚点、不清动作/速度历史；后续外生非零请求结束此停止片段，已锁存失败保留。正式全停场景必须完成确认后5s保持，不能以脚本结束或150s上限补算通过。

## 5. 首版奖励细节（设计参考，未验证）

实际vx/vy取躯干原点worldXY速度按heading投影的水平前向/侧向分量，wz取展开heading差分；奖励速度为本控制步子步均值，姿态/高度为同步后步末值。命令使用本拍锁存的平滑命令，所有角度先换rad，距离m、线速度m/s。`T(e,t)=exp(-(e/t)^2)`；`sx=max(0.005,0.25*abs(vx_cmd))`，`sw=max(1°/s,0.25*abs(wz_cmd))`；`Tx=T(vx-vx_cmd,sx)`，`Tw=T(wz-wz_cmd,sw)`。`mx/mw`表示对应命令非零（对应SI单位零容差1e-6），`m0`表示两者皆零；`Ts=T(norm(v_xy),0.01)*T(wz,3°/s)`。前向任务在所有组合始终有效，目标vx=0时也直接奖励减小残余前向速度。辅助门控`P=Tx*(mw*Tw+(1-mw)*T(wz,3°/s))`，范围[0,1]；只完成旋转而未停止前向运动不能取得满额辅助奖励。

| 项 | 公式（未乘dt） | 权重 |
|---|---|---:|
| 前向任务（含零目标） | `Tx` | +3.0 |
| 转向任务 | `mw*Tw` | +3.0 |
| 全停任务 | `m0*Ts` | +3.0 |
| 侧向抑制 | `P*T(vy,0.01)` | +0.5 |
| 直走航向 | 仅`vx_cmd>0,wz_cmd=0`时 `P*T(wz,3°/s)` | +0.5 |
| 原地保持 | 仅`anchored`时 `P*T(norm(xy-anchor),0.03)` | +1.0 |
| 直立/高度 | `P*T(tilt,15°)*T(z-Z_HOME,0.02)` | +0.5 |
| 动作变化 | `min(mean((a_actual-a_actual_prev)^2)/0.01,1)` | −0.05 |
| 停稳超时 | 平移或完全停止尚未确认且各自时钟超过3s，逻辑或、每拍只罚一次 | −0.5 |

任务三项先求和，再乘`G=T(tilt,20°)*T(z-Z_HOME,0.03)`；其余项相加。`r_step=dt_control*(G*r_task+r_aux-r_smooth-r_late)`，dt_control=0.02s，**只乘一次dt**；若RewardManager自动乘dt，函数返回速率值，不再手乘。失败终止追加一次−100离散代价，不乘dt；时间截断不罚。连续负项上界0.55/s，设计上降低主动摔倒逃避停车惩罚的收益，但不能宣称已证明无投机。

奖励不等于验收：独立计算速度RMSE、方向/进度、5cm最大漂移、15cm减速路径、姿态与失稳。首版不加入无传感器来源的足接触观测，不逐时强约束HOME姿势妨碍迈步。

## 6. 控制时序、测量与失败

每个控制步锁存命令、前一raw动作及前一实际目标，执行10个物理子步。每子步同步forward后读取raw位置/姿态/接触，更新最大漂移、倾角、高度、非足地接触、停车路径和失败锁存；不用默认均值替代极值。按环境mask隔离reset。

控制步结束计算奖励/终止，再推进下一拍命令并构造下一拍61维；保持现有框架“reward后更新command再obs”的顺序。`CommandTerm.compute`区分dt=0/reset与实际推进，不能重复推进。评估`auto_reset=False`，提前reset或截断不能算完成。

位置取`trunk_base`原点worldXY；heading展开后差分得到偏航率，不能把gyro_z无条件当heading导数。每0.02s记录水平速度、速率、roll/pitch角速度；0.2s窗口最多10个已有样本，不填假零，模式变化不清窗口。路径按每0.002s位置差累加，不能用起终点直线距离替代。每回合保存命令/实际速度、锚点时刻、严格失败、终止原因、奖励分项。

失败：任一子步倾角≥45°、躯干高度<0.6*HOME、非足部与地面接触、数值异常；训练另含原地>20cm、平移或完全停止6s超时；评估使用5cm、各自3s确认时限及全停确认后5s保持。环境失败跨控制步锁存，不能因恢复清除。
