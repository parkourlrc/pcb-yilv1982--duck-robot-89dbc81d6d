## 阶段一是否混入转向奖励

用户进一步询问1000轮是否只训前进、转向奖励是否干扰。核对 `STAGE1`、`curriculum_scenario_segments` 和首轮diagnostics：1000轮始终阶段一，仅family1，23秒正前速、目标偏航速度0。虽然共用奖励函数保留转速项，但其系数包含 `turn=(abs(wz)>1e-6)`；阶段一turn为false，转速奖励为0。直走方向项则奖励实际偏航速度接近0，其作用是抑制转动，不是鼓励转向。

因此不能将首轮失败表述为“转向任务的正奖励混入并鼓励转圈”。仍存在独立问题：前向主奖励只看随身体航向旋转的前速，未共同约束航向；偏航变大时较弱的方向辅助趋近0，却不直接取消前向主奖励。此设计可能允许绕行取舍，尚未通过消融确认贡献；动作分布和确定性均值失控已有独立诊断证据。仅解释核对，没有修改奖励或启动训练。

日期：2026-11-06。来源：`training/mjlab_duck/locomotion_env.py` 的 `reward` 与 `failure_cost_rate`，以及 `locomotion_cfg.py`；本轮只核对，没有修改奖励。以下为首轮1000更新使用的实现，不是下一版建议。

定义 `T(e,s)=exp(-(e/s)^2)`，实际前速/侧速为当前航向坐标系的控制周期平均速度，偏航速度也按控制周期平均。

- `tx=T(实际前速-目标前速,max(0.25*abs(目标前速),0.005m/s))`。
- `tw=T(实际偏航速度-目标偏航速度,max(0.25*abs(目标偏航速度),1度/秒))`。
- `y0=T(实际偏航速度,3度/秒)`；实际代码角度使用弧度。
- `P=T(倾角,20度)*T(高度-HOME高度,0.03m)`。
- `G=tx*(转向命令非零时tw，否则y0)`。

| 项 | 奖励率公式 |
|---|---|
| 前速跟踪 | `3*P*tx`，所有命令下均计算，包括零前速 |
| 转速跟踪 | `3*P*tw`，仅转向命令非零 |
| 静止保持 | `3*P*T(水平速度模长,0.01m/s)*y0`，仅前速和转速命令都为零 |
| 抑制侧移 | `0.5*G*T(侧速,0.01m/s)` |
| 直走方向 | `0.5*G*y0`，仅正前速且零转向命令 |
| 锚点保持 | `G*T(当前位置到锚点距离,0.03m)`，仅已建立锚点的phase2 |
| 姿态与高度 | `0.5*G*T(倾角,15度)*T(高度-HOME高度,0.02m)` |
| 动作平滑 | `-0.05*min(mean((actual-previous)^2)/0.01,1)` |
| 超时 | `-0.5`，减速阶段超过3秒，或全停尚未确认且超过3秒；否则0 |

`actual=(限位后关节目标-HOME)/0.5`，不是原始raw动作；平滑项在实际关节目标RMS变化达到0.05rad时饱和。

每控制步0.02秒，实际奖励为上述九项奖励率之和乘0.02，再减去失败终止事件的100分；正常回合结束不扣该失败代价。5cm漂移是独立验收门槛，锚点奖励使用3cm指数尺度，两者不能混同。

首轮始终为阶段一前进，转速、全停、锚点与减速超时项在其正常直走场景不启用。前向主奖励未乘方向因子，方向项会在偏航较大时趋近零；这些是源码事实，不单独构成失败唯一原因。PPO的0.005熵系数属于优化损失，不是上述环境奖励的一项。诊断与改进建议见[失败诊断](step5-diagnosis.md)。
