## 1. 用户确认的需求

2026-11-06第④步清单获用户确认：双Spark总4096环境（每台2048）、每环境每轮64步、两阶段合计上限1000轮；阶段一100%直走，阶段二30%直走/30%移动转弯/20%静止原地/15%联合/5%保持；每100轮保存与开发评估、每200轮诊断，直走连续两个相邻不同检查点9/9通过才进入阶段二，持续退步/覆盖不足按已定规则暂停。预算与课程参数已实现，见[确认清单](step4-confirmation-checklist.md)，运行验证范围单独记录。

2026-11-06用户确定训练顺序为两个阶段：先能正常前进，再加入移动中转向训练。采用同一模型逐阶段继续学习，最终联合动作范围保留；具体课程门槛与下游影响见[两阶段方案](training-curriculum.md)。正式入口已实现该课程；原从首轮混合五族的代码仅保留为旧测速版本，不作为当前启动方案。

用户原话：“把策略需求改成同一个模型同时完成行走、减速和转圈”；随后限定“后退和侧移不用做，只做前进，有旋转方向，这样没有前进就是原地转，有前进就是带角度一边转一边走”。

2026-11-06补充确认：原地转圈既是最终目标，也是阶段二的训练内容，训练覆盖静止起转和移动减速停稳后起转；同一模型、两个顶层阶段、停稳后固定锚点及5cm验收要求保持不变。此确认不扩展为对具体采样比例或总预算的批准。

## 2. 本次变更与下游影响

- 原“walk减速后换转圈模型”的建议废弃，取消跨模型权重/归一化/动作历史交接；保留同一模型的连续状态，行为过渡不reset机器人或动作历史。
- 61维中的`command=[vx,0,wz]`，前进与转向两个量均可变化；头颈4维和躯干6维命令仍为0。原“除wz外12个命令恒零”改为vy及头颈/躯干共11个命令分量恒零。
- 原仅角速度跟踪的四项奖励不足以描述新增前进目标；需加入平移跟踪/侧向偏差目标，按行为阶段处理锚点保持与边界。全程固定起点约束不得用于正常行走。
- 原24回合仅能作为转圈子集；新增直走、弧线行走、前进减速并持续转向、停稳原地转、重新前进及停止的连续场景。
- 独立速度估计方向保留，用于过渡判定与诊断；不成为第①/②步需求确认的额外硬件前置，也不自动扩充61维。用户说明有原始加速度，获取路径留第③步核对；足部接触需估计。
