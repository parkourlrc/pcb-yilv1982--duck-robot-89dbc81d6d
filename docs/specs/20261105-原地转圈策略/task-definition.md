# 前进、减速与转向：联合任务定义 v2

步骤状态（2026-11-05核对）：第②步文档定义完成。行为范围、命令、测量口径、判据、时间线和评估集已齐备，可作为第③步输入；数值来源仍区分用户要求与助手参考，全部能力待训练/评估验证。以下“建议”指证据等级，不表示本步骤定义缺失。

日期：2026-11-05。所属：[需求Spec](spec.md)。第②步首版数值建议已形成，见[验收参考v2.1](acceptance-reference-v2.md)：前进上限0.10 m/s及行走/减速/转弯判据均为用户要求助手推荐的参考值，未实测验证，不冒充逐项确认。此前[转圈v1](task-definition-turn-v1.md)仅为历史子集参考，不能直接作为联合任务完整验收。

## 1. 命令和行为

同一策略连续接收`[vx,vy,wz]=[前进速度,0,有符号转速]`。vx首版建议0～0.10 m/s；wz沿用±π/6 rad/s。世界Z向上，俯视逆时针为左转/正wz。保持原61维接口，无额外离散行为标志。

| vx命令 | wz命令 | 目标行为 |
|---|---|---|
| >0 | 0 | 直线前进 |
| >0 | 正/负 | 前进同时向左/右转弯 |
| 0 | 正/负 | 停止平移后原地向左/右转 |
| 0 | 0 | 停止平移和旋转，保持站立 |

命令不是实际运动：前进命令降为0后可能仍在减速，不能立即宣称已原地转。允许减速同时继续旋转，不再要求先将转向命令归零再停稳。转向使用转速命令，不要求达到某个指定朝向角。

代码只负责命令约束/平滑、行为阶段统计与异常处理；关节动作由同一模型产生。模式改变不切网络、不重置物理状态或上一动作。初态可从站姿开始，训练/评估必须连续经历行走和过渡，不能靠每段重新reset代替。

## 2. 漂移和停车的测量边界

- 从收到减速请求起记录过渡时间、路径长度和相对减速起点的最大水平位移；首版建议3 s内确认停稳、累计路径≤15 cm，与原地5 cm分别验收。
- 在零前进命令下确认实际平移速度及倾斜/晃动满足[参考停稳条件](acceptance-reference-v2.md)后，记录`trunk_base`世界XY为本次原地阶段锚点。此时允许非零偏航速度，不能要求所有角速度为0来判定“平移已停稳”。
- 从锚点建立起，原地转圈、转圈方向反转及停止保持全过程累计最大水平距离，≤0.05 m；不在方向变化或零转速时重置锚点。瞬时越界后回到起点也判失败。
- 若又发出正向行走命令，当前原地片段结束，记录完整结果再进入行走；下一次减速停稳进入原地片段才建立新锚点。正式原地评估期间不插入行走来清除已发生的失败。
- 世界位置/真实速度与接触只用于仿真奖励、终止、独立验收；不加入61维actor输入。实物5 cm仍需独立位置测量，不能以里程估计自证精度。

## 3. 验收保留项与新增项

下表的数值细化现统一见[验收参考v2.1](acceptance-reference-v2.md)，该文件是本任务首版推荐参数入口；下表保留场景分类，不能将旧“待定”误解为没有参考值。

| 场景 | 当前基线 | 待补/限制 |
|---|---|---|
| 静止起转、恒速原地转 | ±5/±15/±30°/s，每方向3 s启动+60 s稳态，种子0/1/2 | 原24回合表保留为子集参考，需按v2锚点逻辑重新检查 |
| 原地停止与方向反转 | 斜率30°/s²；原3 s响应、停止后残余转速≤3°/s保持至少5 s等建议值保留待验证 | 不把命令斜率等同于实测角加速度；原细则见v1，需并入v2评估实现 |
| 直线前进 | 3/6/10 cm/s，3 s启动+20 s稳态；检查跟踪、侧偏和朝向 | 参考值见v2.1，未运行 |
| 前进中左右转 | 3档前速×±15/±30°/s；同时检查前向及转向目标 | 不用直线横向位移或原地5 cm限制弧线运动 |
| 减速同时转向→原地转 | 保留状态，建议3 s内停稳、减速路径≤15 cm，之后5 cm | 停稳判据不要求偏航为0；均待验证 |
| 原地转→前进、行走→停止 | 同模型连续响应，实际运动平滑；停止后保持5 s | 具体窗口/误差见v2.1 |

参考v1的实际转速口径：heading逐步展开后差分，用0.2 s因果滑动均值，不用机体系gyro_z直接代替heading导数；窗口不跨模式重置。原地恒速RMSE参考≤max(1°/s,目标绝对值×20%)，方向正确样本≥95%；这些是既有建议基线，不是新增实测结果。

倒地/低高度/非足部接地/NaN等失败参考沿用v1，具体45°、0.6×HOME等阈值仍为未验证建议。全程采样物理子步极值、失败发生后不被reset掩盖；训练回合时长和联合评估总时长需重新设计，不沿用旧20 s/90 s即宣称覆盖。

## 4. 输入条件与任务参数

当前整机及飞特模型已上机，足部无传感器。实际关节位置/速度、IMU姿态/角速度、反馈新鲜度已有工程证据，见[输入核对](../../references/自主训练平台/本机状态估计输入核对.md)。用户说明原始加速度有，具体获取路径留第③步核对，不阻断第②步需求讨论。

独立速度估计供停稳判断/诊断，需与仿真真值对照后决定可用阈值；传感器/估计器方案不作为本步额外确认关卡。仿真可直接测量实际前进/侧向速度与姿态供训练和验收。既有walk仅作为接口参考，不再作为必须执行减速的第二策略；按本项目自建、从零学习路线训练，不加载其策略权重或归一化统计。

用户授权助手推荐后，提出前进上限0.10 m/s及3/6/10 cm/s验收档位；完整定义见v2.1。它们是设计目标，不是已验证范围；未直接采用旧walk的±0.4 m/s配置为能力结论。后退/侧移不再列为待选能力。下一步将参考目标映射为环境与联合奖励方案，若需改变范围则记录原因与版本。
