## 3. 约束与待核验项

1. [用户确认] 三种资源支持与双机均分是首版要求；切换资源不自动增加全局采样预算。
2. [源码核验] 新训资源选择、checkpoint推理回放、完整恢复分别有兼容条件；单机回放双机策略不等于单机可完整续训。
3. [源码核验] 采集/控制改动可能触及哈希合同中的文件；旧产物须保留原来源和配置，下一阶段明确旧版回放/恢复方式，不将旧产物标为新版本训练成果。
4. [既有实测记录] 联合任务首轮预算耗尽但行为未达标；工具呈现真实曲线，算法稳定化仍归原训练任务。
5. [待核验] WSL/节点当前状态、三种启动路径、监控字段支持、回放位置和并发性能、远端checkpoint取用方式，留待方案/实施按需核查。本轮未查询实时设备状态，不依据旧路径和历史吞吐作性能承诺。
6. [来源原件已取得] 使用部署固定版本Studio显示模型，保持训练物理契约；根据checkpoint仿真位姿显示。来源哈希与加载方式已查明，关节适配在实施阶段完成；当前主控内容未重新比对的限制不等于没有源码或模型。
