# 下一轮提案：保留20mm足部目标，单独比较航向罚项

日期：2026-11-08。状态：**待用户确认，未编码、未启动新增训练**。承接原“持续优化小摆幅”的目标；本提案增加独立方向奖励，超出已完成四组足部/平滑对照的具体配方，按AGENTS.md第四节第8条确认后实施。

## 依据与待验证问题

[实测，仿真] [本轮完整结果](../../references/自主训练平台/足部奖励百轮对照-20261107.md)显示，20mm组在场景101/102形成32/42、34/42次有效起落，交替86.3%/89.3%，左右膝逐周期中位摆幅约15.3°/10.8°；场景103仍静止。前两场前速约0.0207m/s，偏航约133.8°/64.3°，dev9为0/9。物理参数相同已能产生较大动作，但直行和起步一致性不合格。

[源码核验/实测] 当前直行方向项受速度核与瞬时偏航核相乘门控。场景101确定性腾空、前进、直行偏航奖励率均值分别约1.104、0.325、0.00270。

[假设] 独立的偏航罚项能向已形成的步态提供方向修正信号。替代解释包括百轮预算、初始条件、探索噪声、奖励权衡与子步数值振荡；该罚项也可能让策略更倾向静止或缩小摆幅，必须在结果中检查，不能预设成功。

## 两组具体对照

- 共同保留`gait020`全部设置：足底目标20mm、腾空窗口0.125–0.300s及原足部权重，沿用原饱和平滑项，不加入压缩raw渐进课程。
- 仅新增一个方向罚项：直行移动命令下，`r_heading = -w * (mean_yaw_rate_200ms / 0.5)^2`。单位为奖励率，继续由现有RewardManager乘0.02s。`mean_yaw_rate_200ms`取现有控制步窗口中的偏航角速度均值，初期按实际有效样本数平均；这是奖励统计窗口，不改变动作、指令或执行器滤波。
- 直行移动门控为`cmd_vx > 0`且`abs(cmd_wz) <= 1e-6`；站立和转向不启用。每组只改变`w`：**0.3、1.0**，与既有`gait020`的`w=0`比较。
- [离线算术，非重训预测] 在场景101/102原有轨迹上，`w=0.3`对应平均罚率约−0.0469/−0.0352；`w=1.0`约−0.1563/−0.1172。仅用于检查量纲与量级，策略重新训练后分布会改变。源数据见[离线量级记录](../../references/自主训练平台/gait-experiments-20261107/comparison/heading-proposal-scale.json)。
- Kp25、Kd2、力矩0.94、质量惯量、摩擦、碰撞、HOME、物理步长2ms、控制50Hz、action scale0.5、网络/PPO、探索和速度任务均固定。不增加对称损失，不切换BAM，不操作实物。
