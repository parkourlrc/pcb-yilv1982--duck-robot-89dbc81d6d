# HAT A.1 r18：THT后焊方式及间距约束

2026-11-03。源86654c03b6c1c8f51f7d5a4bef469aceed2ddfc73433b3e50426940c2a23164a；r18拼板fd6cd170fc09848e37feb88e10dad3bbf1d21954a8139f7bb0f8a303e4ceb22c。此文件是设计工序选择，不是工厂已接受、已焊接或实物通过。

采用顺序：B面SMT→F面SMT→全部6件/单元THT局部逐点手工焊接。禁止把笼统“后焊”解释为整板波峰焊或通孔再流焊。选择性焊接若被提出为替代，需有实际喷嘴/托盘/热影响评估，当前没有自动批准。

嘉立创62761第2节说明，插件引脚5mm内有贴片件无法进行波峰焊。按原生59个钻孔完整圆与反面52个SMT的Fab框筛查，6个连接器均有低于5mm的邻近位置；这是文件包络筛查，不是实际焊接工具可达性或温度测试。

手工逐点不等于可以忽略邻近器件：尤其J403.3附近R703，仍需按实际烙铁头、加热时间、焊料与夹具检查可达性和热影响。使用与具体MPN匹配的焊接窗口；本文件不填未经原厂/工艺确认的统一烙铁温度。安装方向、润湿/填孔、桥连、塑料变形、针脚突出与焊后清洁按实际过程验收。没有为逃避几何问题改变元件/网络、扩大板框或减少功能。
