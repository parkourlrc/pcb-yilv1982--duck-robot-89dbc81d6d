本包按嘉立创国内“下单前技术员必看”的格式要求，由KiCad 10原生重新导出为RS-274-X，关闭X2和网表属性。11个Gerber层的绘图命令已与原审查包逐项比较，几何不变；原钻孔、BOM、坐标和装配资料保持，C307不装的钢网去开口策略保留。主板没有改动。本包替代之前X2包作为嘉立创国内格式准备资料。

## 设计参数及选项草案

- 65×30mm、4层FR4、标称1.6mm，内外层铜厚意向1oz；实际层叠编号尚未选定。
- 全部100个via为机械贯通孔；唯一U701.7为0.35mm铜盘/0.15mm设计孔，直径差0.20mm、名义单边环宽0.10mm。公开能力表允许该名义尺寸，0.15mm仍属非常规孔径。
- 6处填孔盖铜：U301五个0.3mm孔及U701.7一个0.15mm孔，位置见fabrication/via-process-requirements.csv。应使用树脂或铜浆填孔并电镀盖帽，不能改为普通盖油。四层板应明确选择相应工艺，不能套用六层及以上默认规则。
- U701.7为0.875×0.25mm矩形与0.35mm过孔铜盘联合形状；阻焊开窗按现有文件。官方盘中孔指引提示贴片焊盘小于过孔时应扇出，此处窄边0.25mm小于过孔铜盘0.35mm，是尚未关闭的具体设计项，不能由孔径/环宽通过代替。
- 双面52 SMT+6 THT、C307 DNP；当前是65×30mm单板资料，尚非嘉立创标准型SMT上机拼板。工艺边/拼板仍需补齐；单板双面fiducial不能代替工艺边要求。
- 建议后续按绿色阻焊、沉金作为工艺核查基线；本轮未选订单参数，不视为用户已决定或已下单。
